\subsection{Вибір та обґрунтування інструментальних засобів розробки}

Реалізація алгоритму двовимірної барицентричної інтерполяції для масштабування зображень вимагає ретельного підбору інструментарію, здатного забезпечити високу швидкість обчислень, ефективну роботу з пам'яттю та гнучкість процесу розробки.

Мовою програмування для створення кінцевого програмного продукту обрано C++. Цей вибір фундаментально зумовлений високими вимогами до обчислювальної продуктивності. Обробка растрових матриць із високою роздільною здатністю передбачає виконання мільйонів математичних операцій з плаваючою комою. Мова C++ надає прямий контроль над виділенням та звільненням пам'яті, а також дозволяє виконувати низькорівневу оптимізацію циклів, що є критично важливим для мінімізації часу виконання алгоритму.

Для проєктування та реалізації графічного інтерфейсу користувача (GUI) було обрано кросплатформний фреймворк Qt (версії 6). Завдяки спеціалізованим класам \texttt{QImage} та \texttt{QPixmap} реалізовано ефективні механізми прямого доступу до піксельних даних у пам'яті, що дозволяє мінімізувати накладні витрати під час виведення відмасштабованого зображення на екран. Архітектурно програмне рішення розділене на обчислювальне ядро та графічний інтерфейс. Взаємодія між ними відбувається через базовий для Qt механізм сигналів і слотів, що дозволило інкапсулювати складні матричні обчислення, не перевантажуючи код інтерфейсу.

З метою проведення об'єктивного порівняльного аналізу до проєкту було інтегровано відкриту бібліотеку комп'ютерного зору OpenCV. Її використання дозволило підключити перевірені індустріальні алгоритми масштабування, які виступили в ролі еталонних рішень для тестування продуктивності та точності розроблених барицентричних підходів.

Управління процесом збірки проєкту, налаштування залежностей (Qt, OpenCV) та автоматизація компіляції здійснюється за допомогою кросплатформної системи CMake. Використання CMake забезпечило чітку ієрархію проєкту з логічним розділенням на підкаталоги, ізольовану генерацію файлів збірки та можливість легкого розгортання вихідного коду на різних операційних системах.

Середовище MATLAB застосовувалося виключно на підготовчому етапі для генерації еталонного тестового зображення. Завдяки вбудованим інструментам для роботи з матричними структурами, у MATLAB було сформовано вихідний масив даних із чітко заданими просторовими характеристиками. Це тестове зображення надалі використовувалося для верифікації обчислювальної коректності розробленого алгоритму та аналізу якості фінального масштабування.
